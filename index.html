APRENDER, SIN COMPLICACIONES

Una biblioteca.
Muchas posibilidades.

Material introductorio elaborado para este proyecto académico. No necesitas una cuenta para empezar.

¿Cómo encuentro una guía?

Escribe una palabra en el buscador y combina los filtros de tema y nivel. Selecciona «Leer guía» para abrir el contenido completo.

¿Dónde se guarda mi lista?

En el almacenamiento local de este navegador. No se sincroniza con otros equipos y puede borrarse al limpiar los datos del navegador. Si el almacenamiento está bloqueado, la lista funciona durante esta visita.

¿Puedo acceder sin conexión?

Si tienes la carpeta completa del proyecto, puedes abrir index.html para consultar las guías. Se recomienda un servidor local para que la persistencia tenga un origen estable.

¿Qué incluye cada lectura?

Una explicación breve, una orientación de uso y un ejercicio práctico. Los tiempos de lectura son estimaciones editoriales, no mediciones con usuarios.
